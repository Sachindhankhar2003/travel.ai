🎯 FASTEST WAY - Use Android Studio:
═══════════════════════════════════════════════════════════════════════════

   1. Open Android Studio

   2. File → Open → Select "Travel.ai" folder → OK

   3. Wait 2 minutes (Gradle sync)

   4. Build → Build APK(s)  [or press Ctrl+Shift+F9]

   5. Wait 2-3 minutes

   6. Click "locate" when build finishes

   7. Copy app-debug.apk to your phone

   8. Install on phone!


📁 APK Location After Build:
═══════════════════════════════════════════════════════════════════════════

   C:\Users\Public\Desktop\Travel.ai\app\build\outputs\apk\debug\app-debug.apk


📲 How to Install on Phone:
═══════════════════════════════════════════════════════════════════════════

   • Copy APK to phone (USB cable / Google Drive / Bluetooth)
   • Open APK file on phone
   • Allow "Install from unknown sources" (Settings → Security)
   • Click Install
   • Click Open
   • Done! 🎉
